# Likhitha Bandaru Portfolio

A premium software engineering portfolio for a Data & AI-focused candidate, built with Next.js and TypeScript.

## Overview

This portfolio reflects the updated resume for Likhitha Bandaru and includes:
- a strong data and AI-focused hero section
- about and engineering philosophy content
- skills aligned to Python, SQL, data engineering, LLMs, and governance
- project case studies for SmartData Assist, DataPulse, and InsightML
- education and AWS certification details
- a working resume download
- a responsive light/dark theme

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production build

```bash
npm run build
npm run start
```

## Resume asset

The verified resume is stored in:

`public/Likhitha_Bandaru_Software_Engineer_Resume.pdf`

## Deployment

### Recommended: Vercel

1. Push the project to a GitHub repository you control.
2. Import the repository in Vercel.
3. Use the default Next.js build configuration.
4. Deploy.

### GitHub push note

This environment does not have your personal GitHub authentication or a verified repo URL for a live push. The project is prepared and ready to be pushed once you provide the repository you want to use.
